# Window decorations AirSkyOS-light / AirSkyOS-dark (Aurorae)

Based on **ChromeOS-kde** by Vince Liuice (<https://github.com/vinceliuice/ChromeOS-kde>),
itself based on materia-kde by Alexey Varfolomeev. GPL-3.0 (see `LICENSE` in each folder).

AirSkyOS changes (applied while the package is built, see
`packages/airskyos-kde-theme/PKGBUILD` and `aurorae-buttons.py`):
white (light) / black (dark) discs behind the title-bar buttons,
buttons and title moved 10 px to the right, white title text in the dark variant.
